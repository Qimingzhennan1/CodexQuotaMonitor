# Codex 多屏额度悬浮监视器设计

## 目标

在保留现有系统托盘功能的同时，增加一个类似 FPS 监视器的常驻悬浮窗。悬浮窗可以拖到任意显示器，支持三种布局、置顶与可切换的鼠标穿透，并在显示器拓扑变化后保持可见。

## 已确认的交互

- 保留现有托盘图标、详情、刷新、已用/可用切换、开机启动和退出功能。
- 悬浮窗提供完整横版、极简横条和紧凑竖版三种布局。
- 右键悬浮窗或托盘可选择布局；双击悬浮窗循环切换布局。
- 非穿透状态下，左键拖动悬浮窗；拖动结束后保存位置。
- 默认置顶，托盘和悬浮窗菜单均可切换置顶状态。
- 鼠标穿透可切换。开启后所有鼠标事件落到后方窗口，只能通过托盘菜单关闭穿透。
- 保存当前布局、位置、置顶、穿透、显示/隐藏和已用/可用状态，重启后恢复。
- 显示器断开、分辨率或缩放变化导致保存位置不可见时，将悬浮窗移到当前主屏工作区左上角。

## 额度展示

- 不写死“5 小时”或固定窗口数量，根据接口实际返回动态生成额度窗口。
- 当前账户接口只返回一个 604800 秒的每周窗口，因此默认显示“每周”。
- 若未来接口重新返回第二窗口，完整横版动态增加一行；极简和竖版继续突出主窗口，并在辅助区域显示第二窗口摘要。
- 支持显示已用百分比或可用百分比，悬浮窗与托盘口径一致。
- 颜色阈值沿用绿、黄、红三级语义。
- 显示重置倒计时和最后成功更新时间。

## 异常状态

- 网络、认证、HTTP 或 JSON 解析失败时，状态必须转为异常。
- 若存在最后一次成功数据，继续显示数据但增加“数据已过期”标识和最后成功更新时间。
- 若从未成功获取数据，显示错误摘要，不格式化空百分比。
- 接口字段缺失或类型异常时显示“暂无额度数据”，不能导致托盘或悬浮窗崩溃。
- 网络恢复并成功刷新后自动清除异常标识。

## 组件边界

### QuotaService

负责加载令牌、后台请求、校验接口结构和生成统一额度快照。通过单一刷新锁避免定时刷新与手动刷新重叠。

### SettingsStore

使用 `HKCU\Software\CodexQuotaMonitor` 保存用户设置。字段包括窗口坐标、布局、置顶、穿透、可见性和显示口径。读取失败时使用安全默认值。

### OverlayWindow

使用现有 Win32/ctypes 技术实现无边框窗口、三种绘制布局、拖动、双击、右键菜单、置顶、穿透与位置修正。绘制过程中恢复并释放 GDI 对象。

### TrayController

使用现有 pystray 图标，增加悬浮窗显示、布局、置顶和鼠标穿透菜单，并将所有网络刷新放到后台线程。

## 数据流

1. 启动时加载设置并创建托盘与悬浮窗。
2. 后台线程获取额度并生成不可变快照。
3. 托盘与悬浮窗读取同一份快照并刷新显示。
4. 用户交互更新设置和窗口样式；需要持久化的设置写入注册表。
5. 显示器拓扑变化或恢复窗口时校验坐标，必要时回退到主屏工作区左上角。

## 验证

- 使用模拟响应测试单窗口、双窗口、缺失字段和异常响应的解析。
- 测试失败刷新会标记旧数据过期，成功恢复会清除异常。
- 测试布局循环、设置序列化和不可见坐标修正的纯逻辑。
- 运行 Python 语法编译与依赖检查。
- 在 Windows 上冒烟验证窗口创建、拖动、三种布局、置顶、穿透、托盘恢复操作以及退出后的资源清理。

## 非目标

- 不修改 Windows 系统任务栏或模拟第二通知区域。
- 不增加 Rainmeter、Qt、Electron 等外部 UI 运行时。
- 不访问额度查询以外的新网络服务。
