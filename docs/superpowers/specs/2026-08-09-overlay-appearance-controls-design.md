# 悬浮窗配色与透明度设计

## 目标

提高悬浮额度在终端、浏览器和桌面背景上的辨识度，同时保持功能简单。

## 配色

悬浮窗和托盘右键菜单增加“配色模式”：

- 整体主题：文字、百分比和进度条统一使用主题色。
- 仅高亮：百分比和进度条使用主题色，其他文字使用高对比亮白。
- 分别设置：主题色与文字色分别选择。

主题色和文字色均使用四种预设：绿色、青色、橙色、白色。不增加颜色选择器。

额度达到警告阈值时，红色和黄色告警颜色优先于用户主题色，避免失去风险提示。

## 透明度

增加 50%、70%、85%、100% 四档整体窗口透明度。选择后立即更新当前悬浮窗。

## 持久化与交互

- 保存配色模式、主题色、文字色和透明度到现有注册表设置键。
- 重启后恢复上次选择。
- 托盘菜单与悬浮窗右键菜单提供相同选项。
- 不新增窗口、依赖或自由颜色输入。

## 验证

- 验证设置能保存和恢复。
- 冒烟检查三种配色模式、四种颜色和四档透明度能即时切换。
