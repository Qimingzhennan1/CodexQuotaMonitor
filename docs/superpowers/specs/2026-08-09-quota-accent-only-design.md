# 额度强调色范围设计

## 目标

让用户选择的配色只强调额度数值，不再影响悬浮窗的普通文字。

## 显示规则

- 完整版：百分比数字和进度条已填充部分使用所选颜色。
- 竖版：大号百分比和进度条已填充部分使用所选颜色。
- 极简版：只有百分比数字使用所选颜色；左侧小方块使用固定灰色。
- 标题和额度名称使用固定亮白色。
- 重置时间和更新时间使用固定灰色。
- 进度条未填充部分保持深灰色。
- 达到现有警告阈值时，仅百分比和进度条填充临时覆盖为黄色或红色。

## 交互与兼容

- 继续使用现有单一“配色”入口和 `accent_color` 设置。
- 透明度、布局、置顶、鼠标穿透及托盘行为不变。
- 不增加新设置、依赖或窗口。

## 验证

- 保留现有配色与警告覆盖测试。
- 增加一个绘制配色映射测试，验证普通文字颜色固定、额度强调色可选。
- 运行现有测试、语法检查并重启程序。
