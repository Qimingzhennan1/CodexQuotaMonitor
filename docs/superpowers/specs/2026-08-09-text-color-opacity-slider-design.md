# 文字颜色与透明度滑块设计

## 目标

- 选择文字颜色后立即在悬浮窗中可见。
- 将固定透明度档位改为 20%–100% 的滑块，拖动实时预览并保存。

## 设计

- `set_text_color()` 在保存颜色时同步切换为 `split` 配色模式，保留现有三种配色模式的含义。
- 托盘菜单和悬浮窗菜单把透明度入口改成“调整透明度…”。
- 入口向悬浮窗线程发送消息，在鼠标附近显示一个置顶的 Windows 原生滑块小窗；滑动时调用现有 `set_opacity()`。
- 滑块失去焦点或按 Esc 后关闭；鼠标穿透只作用于悬浮窗，不妨碍滑块操作。
- 注册表继续保存整数透明度，但校验范围改为 20–100。

## 验证

- 一个控制器测试验证文字颜色会自动启用分离配色并保存两项设置。
- 一个设置测试验证任意 20–100 的透明度可保存，越界值回退到默认值。
- 运行现有单元测试、语法检查，并启动程序做一次存活检查。
