# 精简菜单设计

## 目标

保留现有全部功能，通过按使用场景分组减少顶层菜单长度和视觉负担。

## 悬浮窗右键菜单

悬浮窗只提供即时操作：

1. `样式：当前样式`：点击后在完整横版、极简横条、紧凑竖版之间循环。
2. `配色：当前颜色`：点击后在绿色、青色、橙色、白色之间循环。
3. `调整透明度…`：打开现有透明度滑块。
4. 分隔线。
5. `鼠标穿透`：切换鼠标穿透；启用后仍通过托盘关闭。
6. `隐藏悬浮窗`。

“始终置顶”从悬浮窗菜单移至托盘的“更多设置”。

## 托盘菜单

托盘保留完整控制能力，顶层结构为：

1. `显示/隐藏悬浮窗`。
2. `悬浮样式 ›`：完整横版、极简横条、紧凑竖版。
3. `外观 ›`：配色子菜单、调整透明度。
4. `鼠标穿透`。
5. `刷新`。
6. `更多设置 ›`：始终置顶、显示口径、开机启动。
7. 分隔线。
8. `退出`。

## 行为与兼容

- 所有现有设置、注册表值和快捷操作继续有效。
- 菜单操作后继续即时刷新勾选状态和文字状态。
- 不增加设置窗口、依赖或新的持久化字段。
- 悬浮样式、配色、透明度、置顶、穿透、显示口径、刷新、开机启动和退出功能均保留。

## 验证

- 用纯函数描述两个菜单的顶层结构，并验证顶层项目数量与分组内容。
- 运行现有单元测试和语法检查。
- 重启程序，检查新版进程存活以及悬浮窗菜单能正常打开。
